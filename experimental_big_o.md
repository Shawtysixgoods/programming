# Лабораторная работа: Эмпирический анализатор сложности алгоритмов сортировки (Python)
---
### Описание задачи
Вам необходимо разработать консольное приложение на Python, которое:
1. Запрашивает у пользователя параметры для генерации случайных чисел (размер массива, диапазон значений).
2. Позволяет выбрать один из 4-х встроенных алгоритмов сортировки.
3. Проводит автоматический замер скорости работы и **экспериментально определяет временную сложность**
4. выбранного алгоритма (\(O(N \log N)\) или \(O(N^2)\)), основываясь на методе коэффициента роста.

Запрещается использовать ООП.

---

### Архитектурные требования к коду
Программа должна демонстрировать:

1. **Интерфейсный и Алгоритмический блок:**
   * Меню пользователя, валидация ввода и обработка выбора через циклы `while`/`for`.
   * Классическая реализация 4-х алгоритмов сортировки: **пузырьковая (Bubble)**, **вставками (Insertion)**, **выбором (Selection)** и **слиянием (Merge Sort)**.
2. **Аналитический блок:**
   * Блок кода, который управляет запуском тестов, собирает время работы и рассчитывает итоговую сложность.
---

### Алгоритм автоматического определения Big O
Вместо сложной математической подгонки кривых, 
программа должна использовать **метод коэффициента роста при удвоении задачи**:

1. **Замер для \(N\):** На сгенерированном массиве размера \(N\) алгоритм сортировки запускается \(3\) раза. Программа фиксирует **минимальное** время выполнения (\(T_1\)). Выбор минимального времени из нескольких попыток обязателен, чтобы отсечь случайный системный шум ОС.
2. **Замер для \(2N\):** Программа автоматически генерирует аналогичный случайный массив, но уже размера \(2N\) (в два раза больше). Процедура с 3 запусками повторяется, фиксируется минимальное время (\(T_2\)).
3. **Расчёт коэффициента:** Вычисляется коэффициент замедления: 
   \[K_{growth} = \frac{T_2}{T_1}\]
4. **Интерпретация результатов:**
   * Если \(1.6 \le K_{growth} \le 2.6\) выводится сложность **\(O(N \log N)\)** (характерно для сортировки слиянием).
   * Если \(K_{growth} \ge 3.0\) выводится сложность **\(O(N^2)\)** (характерно для пузырька, вставок и выбора).

* **«Удовлетворительно» (3 балла):** Работает консольный интерфейс, корректно генерируются случайные данные в заданном диапазоне. Реализованы все 4 алгоритма сортировки. Эмпирический анализ написан обычными циклами в императивном стиле.
* **«Хорошо» (4 балла):** Выполнены все условия базового уровня. Аналитический блок (замеры времени, вызов сортировок на тестах, расчет коэффициента) написан строго в **функциональном стиле** (без циклов, на `map`/генераторах/рекурсии).
* **«Отлично» (5 баллов):** Программа полностью соответствует требованиям, написана чисто и аккуратно. За счет правильной фильтрации шума времени (поиск минимума из серий запусков) анализатор стабильно и безошибочно отличает эффективную сортировку слиянием от трех квадратичных.
